# Карточка начала тренировки: варианты

Пять отдельных превью для выбора оформления. Рабочий главный экран пока не меняется.

Открыть `index.html` через локальный HTTP-сервер. `comparison.png` — общий лист сравнения; `variant-*.svg` — отдельные макеты с одинаковым текстом и действием.

| № | Направление | Что меняется |
|---|---|---|
| 01 | Мягкий акцент | Знакомая карточка с угловой графикой и отдельной кнопкой |
| 02 | Большая кнопка | Нижний край карточки становится широкой зоной старта |
| 03 | Ритм движения | Декоративная линия и тёмная кнопка с яркой стрелкой |
| 04 | Лаймовый плакат | Акцентная поверхность, тёмный заголовок и чёрная кнопка |
| 05 | Открытая композиция | Заголовок и кнопка лежат прямо на фоне страницы |

Сохранены палитра GYMIX, заголовок Unbounded, существующая фитнес-иллюстрация, подпись «Собери занятие под себя» и действие «Начать тренировку». Макеты имеют ширину 345 px — ширину содержимого на телефоне 393 px с боковыми отступами 24 px. Иллюстрация взята из `apps/client/src/assets/fitness.png`. Для одинакового вида в SVG, PNG и браузере заголовок встроен в макет как прозрачное изображение, отрисованное из уже установленного шрифта Unbounded; при реализации использовать обычный HTML-текст и существующий шрифт приложения.

После выбора перенести оформление в компонент главного экрана. Сохранить проверку активной тренировки, повторное использование карточки для продолжения занятия, состояние ожидания действия, ошибки, доступную подпись кнопки, клавиатурный фокус и перенос длинных названий. Вся кнопка — единое действие; отдельно кликабельных стрелок или иллюстраций нет. Декоративная линия №03 не является графиком данных или медицинским показателем.
