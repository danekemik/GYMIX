# «Эта неделя»: варианты оформления

Архив превью для выбора дизайна. Пользователь выбрал №02; линия недели применена на главном экране через `WeekActivity variant="timeline"`.

Открыть `index.html` через локальный HTTP-сервер. `comparison.png` — общий лист сравнения, `variant-*.svg` — исходные макеты.

| № | Направление | Отличие |
|---|---|---|
| 01 | Календарь | Все семь дней с датами и отметками занятий |
| 02 | Линия недели | Семь точек на общей линии, без отдельной карточки |
| 03 | Ритм | Число занятий и одинаковые столбики для тренировочных дней |
| 04 | Короткая сводка | Число занятий и только даты завершённых тренировок |
| 05 | Лента дат | Крупные карточки дней с горизонтальной прокруткой |

Во всех макетах одни демонстрационные данные: 12–18 октября, сегодня суббота 17 октября, по одному занятию во вторник, четверг и субботу. Столбики №03 обозначают наличие занятия, а не нагрузку. Кольцо/контур обозначает сегодняшний день, галочка — день с завершённым занятием. Цель по числу тренировок не предполагается.

В рабочем компоненте сохранены загрузка реальных данных, смена недели, доступные подписи, состояния пустой недели и ошибки. Если позже будет выбран №04, число тренировок считать отдельно от количества тренировочных дней; несколько занятий за день не дублируют дату. Для №05 сохранить доступность всех дней через касание и клавиатуру.
