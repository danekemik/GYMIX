# Exercise Catalog V1

Статус: согласованный нормализованный перечень для V1, перенесённый из пользовательского списка 2026-10-05. Таблицы сгруппированы по основным мышечным группам; дублирующиеся движения остаются одной записью упражнения с несколькими связями мышц.

**Уникальных названий упражнений: 113.** В таблицах 118 размещений по группам; пять названий встречаются в двух группах: Отжимания на брусьях, Болгарские приседания, Выпады назад, Step-up, Румынская тяга со штангой.

## Канонические правила каталога (аудит 2026-10-05)

1. **Название группы канонично.** Единственная нормализованная форма — **«Ягодичные»** (анатомически точно и единообразно с остальными девятью группами). Раздел ниже и все связи мышц используют только её; вариант «Ягодицы» не применяется. Так же нормализованы `equipment`-лейблы по таблице алиасов в `exercise_database.md`.
2. **Порядок primary каноничен.** Для упражнения, присутствующего в двух группах, ячейка `Primary` обязана быть **побайтово одинаковой в обеих секциях** и отражать доминирующую группу первой. Раздел «Ягодичные» поэтому показывает у Болгарских приседаний `Квадрицепс, Ягодичные`, а не обратный порядок. Принадлежность записи к разделу определяется наличием группы в ячейке `Primary`, а её порядок задаёт доминирование для ранжирования. `Secondary` содержит только вторичные мышцы и никогда не содержит co-primary группу.
3. **Паттерн many-to-many, но каноничен.** Упражнение может иметь несколько паттернов; в колонке `Паттерн` они перечисляются в каноническом порядке и одинаковы во всех секциях. Для `Отжимания на брусьях` канонический набор — `Horizontal Push, Elbow Extension` (ранее секции расходились: секция «Грудь» давала `Horizontal Push`, секция «Трицепс» — `Elbow Extension`, что невозможно для одной записи).
4. **Дубль названия запрещён.** `Румынская тяга` (Ягодичные) была тем же упражнением, что и `Румынская тяга со штангой` (Задняя поверхность бедра), и объединена с ней. Поэтому уникальных записей 113, а не 114.
5. **Пустой паттерн — дефект данных.** `Trunk Extension` не назначен ни одной записи: для упражнений корпуса применяются `Trunk Flexion`, `Trunk Rotation`, `Anti-Extension`, `Anti-Rotation`. Паттерн остаётся в справочнике как зарезервированный и не удаляется.
6. **Групповые паттерны.** `Horizontal Shoulder Movement` назначен на `Сведение рук в Pec Deck`, `Сведение рук в кроссовере` и `Сведение рук в кроссовере снизу вверх`. Это движения приведения горизонтального плечевого сустава, применённые к грудным записям, и они пересекаются со слотом Pull «задняя дельта». Слот Pull матчится по тегу `rear_delt` в группе «Плечи», а не по этому паттерну, поэтому коллизии в V1 нет.
7. **Слот «задняя дельта» (Pull) — тег, не группа.** Он закрывается упражнениями группы «Плечи», которым назначен тег `rear_delt`: `Разведение гантелей в наклоне`, `Обратная бабочка`, `Face Pull`. Их ровно три, а Pull · Расширенная требует два — покрытие есть, запас минимален. Одиннадцатая верхнеуровневая группа не создаётся.
8. **Покрытие структурами.** Из 113 записей генератору доступны 102 (грудь, спина, плечи, бицепс, трицепс, квадрицепс, задняя поверхность бедра, ягодичные, икры). Оставшиеся **11 записей группы «Пресс» недостижимы ни одной структурой V1** и помечены как только каталог.
