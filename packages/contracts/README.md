# @gymix/contracts

Общие для клиента и сервера схемы Zod, типы операций, результат их применения и коды ошибок API. Пакет не зависит от БД, HTTP-фреймворка или React. Схема таблиц и формат сетевых запросов — отдельные контракты.

`operationSchema` проверяет отдельную операцию, `operationBatchSchema` — ревизию и пакет из 1–100 операций. Клиент должен генерировать UUID операции один раз и сохранять его вместе с исходящим изменением.
